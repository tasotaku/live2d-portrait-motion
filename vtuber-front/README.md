# 正面VTuberの試作

デモ一覧から「正面VTuber」を開くと待機モードで始まります。待機では小さな呼吸と不規則な瞬きが入り、頭はゆっくり姿勢を変えて数秒留まります。「待機の揺れを止める」で、瞬きだけを残して比べられます。

「会話」では3つの字幕に合わせて口が動き、台詞の区切りで小さくうなずきます。「手動」では左右の目、口の開きと横幅、頭の傾きを個別に確認できます。母音ボタンで口形を止めて見比べられます。

## 素材と実装

- `portrait.png`、`closed-eyes.png`、`open-mouth.png` はImageGenで作成した同一キャラの素材です。[画像生成指示](artwork-prompt.txt)
- `draw.mjs` では、上まぶたの線が下がって閉じ目差分につながります。口内のテクスチャは顔に固定し、唇の間から見える範囲を変えます。頭は襟の位置を支点にメッシュを変形し、服の下端を固定します。
- `pose.mjs` に待機と会話の動きを記述しています。瞬き・呼吸・姿勢を別の時間軸で調整できます。
- 動作確認用のブラウザリグです。Cubismのモデルファイルやカメラトラッキングは今後の工程に当たります。
