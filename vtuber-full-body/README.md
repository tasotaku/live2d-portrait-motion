# VTuber 全身の動き

「体重移動」では左右に体重を移して数秒とどまり、「軽い屈伸」では両足を置いたまま沈み込んで戻ります。「待機」には呼吸が入ります。右側には胸と髪が少し遅れて戻る動きを加えています。「上半身を拡大」でその差を確認でき、再生位置のスライダーで左右を同じ場所に止められます。

- [静止画](portrait.png) は成人の全身立ち絵。暗い長髪、無地のTシャツ、パンツ、スニーカーをImageGenで生成しました。[画像生成指示](artwork-prompt.txt)
- `motion.mjs` は体の姿勢と、減衰する胸・髪の動きを同じ時刻で計算します。`draw.mjs` が足・腰・肩・胸・髪に対応するイラスト領域を2Dメッシュで変形します。
- WebGL 2 のブラウザ試作です。今回は正面の体重移動と屈伸で、奥行き方向へのターンや歩行は含みません。

## 全身動作の制作メモ

- **脚全体の圧縮で屈伸を作らない。** この試作では靴を固定したまま腰を下げた結果、膝が曲がる動きより脚の画像が縮む歪みが目立った。体重移動も、腰をずらすだけでは支持脚に体重が乗って見えない。股関節・膝・足首で動きを組み立て、足の接地、曲げた膝の輪郭、服の重なりとシワを主要な姿勢とその中間で確認する。[Live2D公式の接地チュートリアル](https://docs.live2d.com/cubism-editor-tutorials/parameter-controller-tips/#歩きのモーションを作る)
- **画面内の回転は関節を支点にする。** 肘を曲げる場合は上腕・前腕・手を分け、前腕と手を肘のまわりで回す。関節の境目には重なる部分を描き足し、必要なら曲げた角度の輪郭をキーフォームで整える。[Live2D公式講座の前腕の例](https://www.youtube.com/watch?v=6APi9WUkDzw&t=2932s)
- **画面の奥行きは、移動と向きの変化を分けて考える。** 見える向きが一定なら、位置・倍率・描画順で接近や遠ざかりを表現できる。方向転換で見える面が増える場合は、元のレイヤーにその面がすでに描かれているかを確認する。足りない場合は、該当パーツの側面・背面などを描き足すか、向き別の素材を用意する。公式の高可動な靴の例では側面と靴底の素材を用意している。[Live2D JUKU「高可動な足の作り方」](https://juku.live2dcs.jp/course/course-57/)
- **遠近短縮は姿勢に合わせる。** 正面の屈伸で太ももがカメラを向けば、画面上の長さが短く見える。その姿勢の膝の位置、輪郭、重なりと一緒に調整する。斜め向きなどは既存パーツの変形と重なりの調整で表現できる範囲もある。Cubismの「3D回転表現の適用」は、既存パーツの変形から立体的なキーフォームを作る補助に使える。[Cubismマニュアル](https://docs.live2d.com/cubism-editor-manual/apply-3d-rotation-expression/)
