# VTuber 全身の動き

重心移動、肘曲げ、横向きの歩行を切り替えられます。「関節ガイド」で支点を表示し、再生位置のスライダーで途中の姿勢を確認できます。

- [静止画](portrait.png) は成人の全身立ち絵。暗い長髪、無地のTシャツ、パンツ、スニーカーをImageGenで生成しました。[画像生成指示](artwork-prompt.txt)
- **重心移動**は両足の着地点を固定し、移動した腰と足首の位置から膝を求めます。抜重した側の膝は少し手前に曲げます。
- **肘曲げ**は横向きの素材で、上腕と肘の位置を固定し、前腕と手を前に上げます。肘の周りは支点からの距離を保ちつつ、上腕から前腕へ回転角をなだらかにつなぎます。深く曲げるときは、上腕に触れる前腕の付け根の内側にだけ厚みを戻します。
- **歩行**は [横向きの絵](walk-profile.png) と [腕に隠れていた部分を描き足した絵](walk-profile-under-arm.png) を使います。横から追従するカメラに合わせて床の目盛りが動きます。かかとで接地し、つま先で蹴って足を前に運びます。
- WebGL 2 のブラウザ試作です。`motion.mjs` が関節の位置と角度を計算し、`draw.mjs` が元絵を関節ごとに変形・合成します。

## 全身動作の制作メモ

- **脚全体の圧縮で屈伸を作らない。** 前の試作では靴を固定したまま腰を下げた結果、膝が曲がる動きより脚の画像が縮む歪みが目立った。体重移動も、腰をずらすだけでは支持脚に体重が乗って見えない。股関節・膝・足首で動きを組み立て、足の接地、曲げた膝の輪郭、服の重なりとシワを主要な姿勢とその中間で確認する。[Live2D公式の接地チュートリアル](https://docs.live2d.com/cubism-editor-tutorials/parameter-controller-tips/#歩きのモーションを作る)
- **画面内の回転は関節を支点にする。** 肘を曲げる場合は上腕・前腕・手を分け、前腕と手を肘のまわりで回す。関節の境目には重なる部分を描き足し、必要なら曲げた角度の輪郭をキーフォームで整える。[Live2D公式講座の前腕の例](https://www.youtube.com/watch?v=6APi9WUkDzw&t=2932s)
- **曲がる面が見える向きを選ぶ。** 正面の腕を胴の前へ平面的に回した試作では、内側に折れて骨が曲がるように見えた。横向きでは、肘を中心に上腕と前腕の角度が変わる様子が読み取りやすい。正面で同じ動作を作る際は、手前に起きる前腕の短縮や、手と上腕の重なりを別途作る。
- **画面の奥行きは、移動と向きの変化を分けて考える。** 見える向きが一定なら、位置・倍率・描画順で接近や遠ざかりを表現できる。方向転換で見える面が増える場合は、元のレイヤーにその面がすでに描かれているかを確認する。足りない場合は、該当パーツの側面・背面などを描き足すか、向き別の素材を用意する。公式の高可動な靴の例では側面と靴底の素材を用意している。[Live2D JUKU「高可動な足の作り方」](https://juku.live2dcs.jp/course/course-57/)
- **遠近短縮は姿勢に合わせる。** 正面の屈伸で太ももがカメラを向けば、画面上の長さが短く見える。その姿勢の膝の位置、輪郭、重なりと一緒に調整する。斜め向きなどは既存パーツの変形と重なりの調整で表現できる範囲もある。Cubismの「3D回転表現の適用」は、既存パーツの変形から立体的なキーフォームを作る補助に使える。[Cubismマニュアル](https://docs.live2d.com/cubism-editor-manual/apply-3d-rotation-expression/)

### 関節を曲げたときの厚み

1. **関節の外側は、支点まわりの回転で丸みを保つ。** 上腕側と前腕側の変形後の頂点位置を足して平均すると、曲げ角度が大きいほど中間の点が支点側に寄り、肘そのものがしぼむ。各点を支点の周りに回し、関節付近だけ回転角をなだらかにつなぐと、各点の支点からの距離を保てる。
2. **曲げる内側は、関節のすぐ先まで別に確認する。** 支点からの距離を保っても、場所ごとに回転角が違うと、隣り合う頂点は近づく。横向きの肘では深く曲げたところで前腕の付け根がへこみ、上腕にはまり込むように見えた。接触する角度に向けて、へこんだ前腕内側にだけ厚みをなだらかに戻す。Cubismで作る場合は、該当する角度のキーフォームで輪郭を整える。補正する角度と範囲は素材に合わせる。
3. **長さ・外側・内側を実際の描画で見る。** 伸ばした状態、曲げ途中、内側が触れ始める角度、最も曲げた姿勢、戻りを同じ拡大率で比較する。肘なら90度付近も見る。前腕の長さと支点に加え、外側の丸み、内側の厚みと接触、輪郭の切れや跳ねを確認する。同じ確認を膝などにも使う。
