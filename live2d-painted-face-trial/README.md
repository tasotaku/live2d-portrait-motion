# 描き込みの多い一枚絵でのLive2D試作

[再生デモ](./)で左右の目を個別に動かせる。口は閉じ口、少し開く、半開き、全開を選べる。「会話を再生」は3つの短い台詞に合わせた7秒の字幕付きループ。[起動手順](../README.md#別のpcで起動する)に従ってサーバーを起動する。

[母音の比較デモ](./vowel-comparison.html)は左右で目と口の開閉を揃え、右だけ `ParamMouthForm` で口の横幅を変える。Cubismでは唇・口角・開口マスクが `MouthVowelShape` の下にあり、上の歯を含む口内画像は顔の座標に固定する。3つの台詞の発音時刻に合わせて `vowel-keys.mjs` の口形を手付けした。既定の再生では両方のモデルと字幕が無音WAVに同期する。

[頭と上半身の比較](./vowel-comparison.html?body=1)は両側で確定した瞬きと母音付き口パクを同じ時刻で再生し、右だけ頭の傾きと肩・胸の上下を加える。ひよりの公式モデルの `Hiyori_m02` と `Hiyori_m04` では頭の傾き、体の姿勢、呼吸にそれぞれキーがあり、同時に同じ幅で動かない。そこを参考に、このキャラ用のカーブを `body-keys.mjs` に付けた。[桃瀬ひよりの公式サンプル](https://www.live2d.com/learn/sample/momose-hiyori/)

[目と口の制作プロンプト](../live2d-face-rig-v1/eye-mouth-rig-prompt.md)を、日本の漫画風に陰影と細い髪を描き込んだ新しいオリジナルキャラで試した。元絵 `portrait.png` と閉じ目・開口の差分を描いた `expressions.png` は内蔵ImageGenで作成した。生成と差分作成の指示は `artwork-prompt.txt` に保存した。差分から閉じたまつ毛、まぶたの肌、開いた口を採取した。

前作のCubismモデルを作業コピーにして、測り直した左右の目と口の座標を既存メッシュの範囲に合わせ、PSDを再インポートした。閉じ際は虹彩が見える隙間を狭めながら、閉じ目のまつ毛を開きかけの線と同じ高さに寄せる。閉じ目のメッシュは開き3%から0%の区間でも下がり続け、全閉で元の閉じ目の絵に着地する。顔の土台は、閉じ目の差分からまつ毛を消した目元を元絵に位置合わせして作った。まぶたの陰影を残し、髪・眉・他の顔の部位は既存素材と境界をなじませている。口は0・30・66・100%にキーを置き、口角の位置をほぼ保ちながら、上唇と下唇の間を広げる。口角と唇が接する縁は `Mouth`、上唇と下唇の色や厚みは `UpperLip` と `LowerLip` に分けた。上下の唇は閉じ口にも残り、同じ絵が動く。上の歯と舌を含む `MouthInterior` は顔に対して固定し、唇の隙間を表す `MouthOpening` でクリッピングする。舌は開き30%でも下唇の奥に赤みが見える位置に合わせた。

目元にかかる前髪は元絵から取り出して `FrontHair` にした。まつ毛と重なって一枚絵から取り出しにくい毛先は、元絵の流れに沿って描き足した。Cubismの描画順を600に設定し、描画順500の目と顔の前に置いている。この試作で別パーツにした範囲は目元にかかる前髪。

`poses.jpg` は閉じ際と口の開閉を拡大した比較画像。`conversation.gif` は会話の実描画を採取した無音のプレビュー。`preview.gif` は初版の確認モーションの記録。

- Cubism Editorの編集用モデルは `painted-face.cmo3`。実行用の入口は `painted-face.model3.json`。確認モーション `demo.motion3.json` は両目、片目ずつ、口の順。会話モーション `conversation.motion3.json` の台詞とタイミングは `conversation-keys.mjs` にある。
- 素材の再生成は前作フォルダーで `npm ci`、このフォルダーで `node assemble.mjs`。基本の `body-and-features.psd`、全閉用の `closed-eyes.psd`、前髪用の `front-hair.psd`、口内と開口マスク用の `mouth-interior.psd`、上下の唇用の `mouth-lips.psd` を出力する。
- メッシュを引き継ぐ場合は前作の編集モデルを別名でコピーし、基本PSDを `face-rig-v2.psd` の差し替え、全閉PSDを `closed-lids.psd` の差し替えとして読み込む。`mouth-interior.psd` と `mouth-lips.psd` は新規アートメッシュとして追加する。上下の唇には口開閉の両端のキーを入れる。全開は素材の位置を使い、全閉では上唇を約7px下げ、下唇を約20px上げて、隙間の縁と合わせる。`MouthOpening` のキーと輪郭を `Mouth` に合わせ、`MouthInterior` のクリッピングに `MouthOpening` を指定し、このモデルでは口内の描画順を510にする。アトラスを確認し、必要な側に閉じ際のキーを加え、対応SDK向けに書き出す。
- 書き出し後は前作フォルダーで `node make-motion.mjs --painted` を実行すると確認モーションと会話モーションが登録される。

## 次のキャラに引き継ぐ目の制作メモ

1. **目元の土台は閉じ目の絵から作る。** 閉じたまつ毛を取り除き、まぶたの丸みを示す肌の陰影を残す。元絵の眉・目頭・目尻に位置を合わせる。今回、開眼の絵から目を消した版では眉下に細い線が残った。閉じ目由来の肌で目元を作った版は、表情パーツをすべて非表示にした状態でも確認できた。
2. **目にかかる毛は手前に分ける。** 前髪の先端だけでなく、目尻ぎりぎりを通って頬へ続く細い毛も拾う。まつ毛と重なって切り出しにくい部分は、前後の髪の流れをつないで描き足す。開眼・半目・全閉で、同じ毛が同じ位置につながって見えるか確認する。
3. **まぶたを閉じる動きは位置と形でつなぐ。** 上まぶたを主に下ろし、下まぶたは少しだけ上げる。瞳はその場でまぶたに隠れるようにする。別素材の閉じ線を使う場合は、隙間を十分に細くして、開きかけの線と閉じ線の高さ・形を合わせる。最後の数%にも形の変化を持たせ、全閉で閉じ線が一本に見えるところまで動かす。
4. **土台と実際の合成を両方見る。** 土台単体でまつ毛や開眼の輪郭が残っていないかを確認する。合成した実行用モデルでは、全開・半目・片目ずつに加え、閉じ際を1〜2%刻みで止めて、線の飛び、虹彩の残り、目尻の毛の途切れを探す。この絵での合成結果は [ポーズ比較](poses.jpg) にある。

## 頭と上半身の動きの作り方

1. `node assemble-performance.mjs` で確定版のPSDから人物と背景を分ける。`performance-features.psd` は顔・服を含む人物の土台と従来の表情パーツ。`performance-background.psd` は奥に固定し、髪や肩が動いて見える縁を補う。
2. `painted-performance.cmo3` では人物の土台を細かくメッシュ分割し、顔のパーツ全体を `HeadAndNeck` に入れた。`ParamAngleZ` では頭の上ほど動きを強くし、首の付け根に向けて弱める。首・襟・肩は連続したメッシュ上にある。
3. その親 `UpperBodyBreath` を `ParamBreath` で動かす。胴の下側を支点にして肩と胸をわずかに持ち上げ、頭も同じ動きについてくる。瞬きと唇のキーは元のまま。
4. CubismでSDK用に書き出した後、`node ../live2d-face-rig-v1/make-motion.mjs --performance` で `performance.motion3.json` を生成し登録する。会話と同じ5.75秒で、頭・肩と胸・目・口のキーが入る。
