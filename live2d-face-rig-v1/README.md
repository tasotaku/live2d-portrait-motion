# 生成イラストからのLive2Dリグ試作

少し斜めを向いた女性のバストアップを内蔵の画像生成で作り、左右の瞬きと無音の口パクを新しいCubismモデルに設定した。プロンプトは `prompt.txt`、元絵は `portrait.png`。

手元のイラスト、PSD、Cubismモデルから同じ作り方で瞬きと口パクを設定するには、[Live2Dの瞬きと口パクを作る制作プロンプト](eye-mouth-rig-prompt.md)を素材と一緒にAIに渡す。

## 上まぶたと口の4つのキーフォーム

[Web版](./index.html) は新しいモデルを再生する。目と口のスライダーで途中の形を止めて見られる。口は閉じ口、少し開く、半開き、全開のボタンでも操作できる。[前のモデル](./index.html?version=1) と同じモーションで見比べられる。

白目をクリッピングマスクにし、元絵から切り出した瞳の位置と大きさを保った。上まぶたが下に降りる動きに合わせてマスクの上側を下げ、下側も少し上げた。閉じ際の短い区間で、左右それぞれに描いた閉じ目へ切り替わる。全閉では閉じ目のArtMeshだけが表示され、開いた状態のまつ毛、白目、瞳は消える。口は1つのArtMeshに開き0・30・66・100%のキーフォームを設定した。口角付近を基準に上側と下側を動かし、中間の形はCubismが補間する。

- `v2/face-rig-v2.cmo3` がCubism Editorの編集用モデル。実行用モデルの入口は `v2/face-rig-v2.model3.json`。
- `v2/preview.gif`、`v2/poses.jpg`、`v2/blink-closeup.png` はWeb版の実際の描画から作成した。拡大画像には閉じ際の8段階を収録した。
- `npm ci` に続き `node assemble-v2.mjs` で基本素材 `v2/face-rig-v2.psd` と左右の閉じ目 `v2/closed-lids.psd` を再生成できる。Cubism Editorで実行用モデルを書き出し直した後は `node make-motion.mjs --v2` で確認用モーションを登録する。

## 最初の試作

- `preview.gif` は書き出したCubismモデルを描画した8秒のループ。先に瞬き、次に口パクを再生する。
- `face-rig.cmo3` はCubism Editor 5.3 FREEで保存した編集用モデル。標準パラメータの「左目 開閉」「右目 開閉」「口 開閉」を個別に操作できる。
- `face-rig.model3.json` は実行用モデルの入口。Cubism Viewerで開き、Motions → Demo → demo.motion3.jsonを再生できる。
- Web版は [デモページ](./index.html) で再生と手動調整ができる。[起動手順](../README.md#別のpcで起動する)に従ってサーバーを起動する。Web版はCubism Core、PixiJS、pixi-live2d-displayをネットから読み込む。

元絵から左右の目を切り出し、顔の下地を補った。口の中と閉じたまぶたの線を描き足した。目と口はArtMeshの縦方向の形と位置を変える。閉じる直前にはまぶたの線を重ねる。中間の形はCubismが補間する。半目では瞳も少し平たくなり、口の開きも控えめな簡易リグ。首かしげは次の段階。

瞬きの修正では、ひよりの半開きと閉眼を見比べた。二重線が出ていたキャラクターの右目は、開き24%に中間の形を追加し、まぶたの線が細くなった開眼素材に沿うよう調整した。両目とも開き0%では開眼素材の不透明度が0になる。`blink-comparison.png` は同じ実行環境で描画した修正前後の比較で、全開と口パクのフレームが修正前と一致することも画素比較で確認した。

`npm ci` に続いて `npm run assemble` を実行すると素材PSDを再生成する。`face-rig.psd` が基本の4レイヤー、`closed-lids.psd` が追加のまぶた2レイヤー。リグはCubism Editorで作成した。実行用モデルを再書き出しした後は `node make-motion.mjs` で確認用モーションを登録する。

PSDの寸法とレイヤーの読み戻し、MOC3とテクスチャの参照、モーションの曲線を検査した。Web版で実際にモデルを読み込み、120フレームを取得して、瞬き中は目だけ、口パク中は口だけが変わり、最後に初期状態へ戻ることを画素比較で確認した。別担当が `poses.jpg` を目視し、両目と口の開閉と頭部の固定を確認した。
