# Live2Dの瞬きと口パクを作る制作プロンプト

渡したキャラクターのイラスト、レイヤー付きPSD、または編集用Cubismモデルを使い、手元の素材とCubism Editorで左右の瞬きと口パクを実際に作ってください。目は上まぶたが瞳を覆って閉じ、全閉では左右それぞれの閉じ目が自然に見えるようにしてください。口は口角を基準に上下の縁が動き、閉じ口から全開まで滑らかにつながるようにしてください。母音に合わせた口の形や音声付き比較を作る場合は、末尾の「開閉だけの版と母音版の再現メモ」を使ってください。完成品として、編集用モデル、実行用モデル、操作できるプレビューと確認画像を渡してください。

## 1. 入力を確認し、パーツを用意する

1. 添付・指定フォルダーから元絵、PSD、`.cmo3`、参照ポーズを探す。元絵やモデルのキャンバスの幅・高さと原点を確認し、キャラクター本人から見た左右で記録する。左右それぞれの目頭・目尻・瞳の中心、左右の口角、上下の唇の中央を元絵で確認する。斜め向きなら手前と奥で目の幅や傾きが異なるので、各側をその絵から採寸する。元絵の開眼時の線、瞳の色と形、顔の角度、陰影と線の質感を基準にし、作業範囲を瞬きと口パクに絞る。
2. 作業用のコピーを作る。`.cmo3` があればCubism Editorでそのコピーを開き、既存のパーツ、パラメータ、ArtMesh、描画順、クリッピングとデフォルト値を確認して使える設定を引き継ぐ。PSDだけあれば既存のレイヤーを活用してCubismに読み込む。統合イラストから始める場合は必要なパーツを切り出し、元絵と同じキャンバス寸法・座標のレイヤー付きPSDを作る。
3. 次の役割を分け、既存素材で足りる役割は流用する。顔の下地、左右それぞれの上まぶたとまつ毛・下まぶた・白目・虹彩と瞳孔（ハイライトを含む）・全閉用の閉じ目、上唇・下唇の輪郭、唇の間の開口マスク、口内。上の歯が見える絵なら、上の歯を唇の絵から分けて、顔に対する位置を合わせた口内の素材に入れる。切り抜きで隠れていた目や口の周りの肌を、近傍の色、陰影、質感で補う。動かしたときに下地が見える範囲まで描き足し、通常時も隙間や元の線の焼き付きが出ないか合成して確認する。
4. 左右の閉じ目はそれぞれの目頭・目尻と顔の角度に合わせて個別に描く。元絵から線色、太さ、先細り、まつ毛の向きを拾い、開眼のまつ毛を消しても一枚で全閉に見える素材にする。追加素材が必要な既存モデルでは、キャンバスと位置を合わせたPSDを開いているモデルに追加する。既存パーツの置き換えが必要なら再インポート時に対応レイヤーを照合し、既存のArtMeshやキーとの関連を確認する。レイヤー名、位置、順番、透明部分をPSDの読み戻しでも確認する。

## 2. Cubismで左右の瞬きを設定する

1. 左目 `ParamEyeLOpen`、右目 `ParamEyeROpen` を本人基準で割り当て、標準の `0` を全閉、`1` を全開とする。左右それぞれのまぶた、白目、瞳、閉じ目のArtMeshを対応する側のパラメータだけで調整できるようにする。全開で元絵を重ね、瞳と目尻・目頭、線や陰影が合うことを確かめる。
2. 目頭と目尻の位置を基準に、上まぶたを主に下ろし、下まぶたを少し上げる。白目の見える開口をまぶたに沿って変形し、そのArtMeshをクリッピングマスクにして瞳を覆う。瞬き中の瞳の位置と大きさは眼球上で保ち、見える形だけがマスクで変わるようにする。半目で上まぶたが瞳の上側を横切り、下まぶたの上がり方は控えめに見えるキーフォームを左右別々に調整する。
3. 全閉直前の短い区間で、開眼側のまぶたと閉じ目の線の両端・カーブ・太さをそろえてから、描画順と不透明度を調整して閉じ目へ受け渡す。開眼側のまつ毛・白目・瞳は閉じ際に短くフェードし、`0` で不透明度 `0` にする。`0` では閉じ目のArtMeshを不透明度 `100%` にして、それだけで閉じ目を描画する。実際の描画で、白目や瞳がマスク設定で残らないことも確かめる。全開側では閉じ目を消す。切替の前後で二重線、線の跳び、輪郭のずれ、開眼素材の残像が見えたら、線の位置とカーブを合わせ直し、必要な側だけに中間キーを足す。開く方向でも同じ軌跡を確かめる。

## 3. Cubismで口の4形を設定する

口開閉 `ParamMouthOpenY` に、閉じ口・少し開いた口・半開き・全開の4つのキーフォームを作る。承認済み作例では `0`、`0.30`、`0.66`、`1`。これを出発点に、素材や既存の動きに合わせて中間キーの位置と各形の開き幅を調整する。閉じ口は元絵の表情に合わせて描き、口の奥が見え始める形から、口内の奥行きが見える全開まで段階を作る。元絵が開いた口なら、元絵に相当するキーで輪郭と質感が合うようにする。

左右の口角をほぼ同じ位置に保ち、上唇の縁は上へ、下唇の縁は下へ動かす。上唇と下唇の内側の輪郭に沿って開口マスクを変形させ、そこから口内が見えるようにクリッピングする。閉じ口では上下の輪郭が一本につながるよう合わせる。上の歯の位置と大きさは顔に対して固定し、開き幅に応じて唇に隠れる範囲だけが変わるようにする。小さく開いた状態では歯を唇の奥に隠し、広く開くにつれて自然に見せる。口内の色や歯の明るさは元絵の線と陰影に合わせる。

4つのキー間もスライダーで往復し、左右の口角、上下の唇の縁、上の歯の見える境界を追う。歯が唇から浮いたり、歯の位置や大きさが口の開きに引っ張られたり、口内がはみ出したりしたら、開口マスクの形、描画順、上下の唇のキーを見直す。

描き込みの多い一枚絵で、同じ位置の上の歯が開き幅に応じて見えるかを確認できる。[口の開閉比較](../live2d-painted-face-trial/poses.jpg)

## 4. 保存し、書き出したモデルを操作して確かめる

1. テクスチャアトラスに描画に必要な全パーツを配置し、閉じ目や口内の欠落、切れ、重なりを確認する。編集用 `.cmo3` を別名で保存し、保存したファイルを閉じてディスクから開き直す。左右の目と口のパラメータを個別に動かし、キーフォーム、描画順、クリッピング、閉じ目が保存されていることを確認する。PSDを作成・更新した場合は、そのPSDも渡せる場所に保存する。
2. 使用先のCubism CoreやViewerに対応した書き出しバージョンとアトラス設定を確認し、Cubism Editorから `.moc3`、テクスチャPNG、`.model3.json` を書き出す。`.model3.json` が示すファイルを同じ相対配置で配布用フォルダーにまとめる。新しく書き出した `.model3.json` を対象ランタイムで開き直し、MOC3とテクスチャが読み込まれ、各パラメータが意図どおり描画されることを確認する。既存モデルでは追加・変更した部品と従来の表示も確認する。
3. 両目の瞬き、左目だけ、右目だけ、口だけを順に動かし、開始時のポーズに戻る反復可能な確認モーションを作る。`.motion3.json` として渡し、実行用モデルから再生できるよう登録する。実行用モデルを読み込む操作プレビューを用意し、再生・停止と3本のスライダーを使えるようにする。手動確認中は再生や自動瞬きを止め、各値で形を静止できるようにする。
4. 実行用モデルの描画から、全開・中間・全閉・再開眼を含む瞬きの軌跡と、4口形および各キーの間の形を確認する。閉じ目への切替の直前・途中・直後を左右別に拡大する。開き量 `10%`、`5%`、`1%`、`0%` は目安とし、実際の切替区間の境界に合わせて必要なコマを足す。口も `0.50` などキーの間で止める。元絵との開眼比較、軌跡、閉じ際の拡大、4口形と中間を、パラメータ値が分かる画像にまとめる。片目を動かしたときに反対の目や口が連動せず、口だけを動かしたときに目と顔の位置が変わらないことを確認する。崩れを見つけたら該当する素材やキーを直し、再保存・再書き出しして描画を確認する。

## 5. 成果物を渡す

最初の完了報告に、編集用 `.cmo3` と制作PSD、実行用 `.model3.json` と同梱物の場所、プレビューの入口と起動方法、確認モーションと比較画像の場所をまとめる。開閉の実測値、再起動時に必要な操作、Cubism Editorとランタイムで確認できたことを記す。素材やEditorの利用状況が判明していれば、その情報で着手する。足りないパーツは補い、判断した前提を報告する。実行できない工程があれば進められる作業を行い、どこまで保存・描画を確認できたかと、未確認の工程・具体的な理由を記す。

## 開閉だけの版と母音版の再現メモ

1. **両方式で口の素材を共用する。** 上唇と下唇の色と厚みを別パーツにし、閉じ口にも同じ唇を残す。唇が接する線と開口マスクを開閉に合わせて動かす。上の歯を顔に対して固定し、舌や口内下部の陰影を唇の間から見せる。少し開いたときにも元絵に合った口内の色が見えるか確かめる。
2. **開閉だけの版は `ParamMouthOpenY` を動かす。** 口角を基準に上下の唇を離し、閉じ口・少し開く・半開き・全開をつなげる。台詞の長さや間に合わせて開閉を付ける。口の横幅は基準の形に置く。
3. **母音版は同じ開閉に横幅の変形を加える。** 上唇・下唇・口角を含む接触線・開口マスクを、口元用の1つのワープデフォーマ（複数のパーツをまとめて変形する枠）の下に置く。口内は顔の座標に固定する。試作では `ParamMouthForm` の `-1` で口をすぼめ、`0` で基準の形、`1` で横に広げた。既存モデルでこのパラメータが笑顔などの表情に使われている場合は、その動きを保てる専用パラメータを使う。基準の形で元の開閉が再現され、横幅を変えても唇と開口マスクが揃うことを確認する。
4. **あいうえおを止めて確認し、音声に合わせてつなぐ。** 「あ」は縦に開き、「い」は浅く横に広げ、「う」は浅くすぼめ、「え」は「い」より開けて横にも広げ、「お」はすぼめつつ縦にも開く。幅と開き量は絵柄に合わせて調整する。試作の値と付けた時刻は [母音の設定例](../live2d-painted-face-trial/vowel-keys.mjs) を参照。台詞の音声に合わせて母音の時刻を置き、無音や間で閉じ口に戻るようにする。
5. **比較では音声・タイミング・開き具合を揃える。** 同じモデルを並べ、両方で同じ口開閉と瞬きを使う。片方にだけ母音ごとの横幅を加え、共通の音声の再生時刻で双方と字幕を動かす。等速と低速で会話を見比べ、「い」と「お」などは左右を同じ開きで止めて確認する。口角、上下の唇、歯の見える位置も確かめる。[実際の比較デモ](../live2d-painted-face-trial/vowel-comparison.html)

今回の比較では、開閉だけでも会話に違和感が少なく、母音版では口の形の使い分けが分かった。母音版は開きと横幅による近似で、発音ごとの細かな舌や唇の動きは試作の評価範囲外。母音版では形とタイミングの設定が増える。どちらを使うかは作品やカットごとに選べるようにする。
